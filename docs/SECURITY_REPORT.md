# 安全边界与验证

本版本新增能力仅为用户授权的只读检测。HTTP请求依赖DSH认证，额外要求同源Origin与cookie；授权按会话、操作范围和十分钟有效期隔离；白名单拒绝任意域名、命令、未知字段与无授权调用。辅助进程不监听网络端口；私有stdio加随机nonce校验，固定脚本和参数，输出/时限有上限。并发限一，卸载或撤销终止当前helper。注册表及进程读取可能因本机策略失败，界面如实展示错误。

安全测试覆盖：错误IPC身份、跨源及缺失Origin、无会话、未授权、跨会话、越权范围、撤销、任意目标、额外命令字段、并发冲突、撤销期间结果丢弃、图片白名单和路由清理。测试明细见FULL_TEST_REPORT与test/unit。

不读取VPN密码、私钥、订阅密钥或浏览历史；不安装软件、不连接VPN、不写DNS或路由。Host诊断字段保持拒绝策略；用户另选分享时仅分享检查状态摘要。Agent提交经过Host上下文验证；返回accepted只表示宿主受理。剪贴板备用复制失败时显示错误，不伪报已复制。

边界：同一操作系统账户下的恶意进程不在隔离模型内；进程名和卸载登记可被伪装，不能作为软件签名或真实性证明。CSP图片仅为固定本地资源。DNS查询和TCP目标可被网络运营方看到；检测前告知并授权。组件不能证明VPN安全、匿名性、DNS无泄漏或全网可达。PowerShell读取作为helper子进程最长8秒结束；进程被强制结束时不保证操作系统立即回收其后代。

本报告为工程检查，不是第三方渗透测试或安全认证。历史测试产物中的引导令牌在本次分发副本内已删去，不改用户全局环境或凭据。
