# Security

Please report security issues privately through GitHub's security advisory
feature instead of opening a public issue. Do not include VPN account
credentials, subscription keys, API keys, private network addresses, or full
diagnostic reports.

The local helper is read-only. It does not install VPN software, connect a VPN,
modify DNS or routes, or read VPN credentials. Its limits are documented in
`docs/LOCAL_HELPER_DESIGN.md` in the source repository.
