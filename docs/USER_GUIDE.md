# 使用与安装说明

需要 Node.js >=20、DSH 0.2.1-rc.5。此包是 DSH 插件，不是 VPN 客户端。

标准安装命令：`dsh plugin --profile web add dsh-vpn-assistant`。安装后重新启动对应 DSH profile。升级与卸载命令见根目录 README。

从源码验证：`npm ci`、`npm test`、`npm pack --dry-run`。浏览器回归和安装生命周期测试需要通过 `DSH_ENTRY` 指向已安装 DSH 的入口，并使用独立测试 profile；不要针对日常 profile 运行。

市场：搜索、筛选、详情与套餐比较；下载中心仅提供官方渠道，待核实信息不补造。选型：填写或跳过需求，查看五维分数、扣分解释及独立资料可信度；汇率是带日期的内置参考值，不是实时报价。安装：七步指导并保存进度，四个平台显示通用示意图；连接结果仍由用户在官方客户端确认。

设备管理：勾选读取范围 → 授权本地检测 → 开始检测。显示宿主系统、登记客户端及进程匹配。网络诊断：选择固定目标、阅读网络请求说明后授权，再开始。结果含时间、依据、可能原因与建议。未授权显示尚未连接；错误保留实际原因。

保存报告会下载当前检测JSON（含DNS服务器等本页信息），请妥善保管。撤销授权并清除结果用于结束检测。AI协助默认不含诊断详情；只有额外勾选分享摘要后才加入项目状态。

AI协助：预览上下文后可发送到DSH新对话；收到“已受理”后到DSH原生会话列表打开显示的ID。它不表示模型已经回答。宿主未提供sessions服务或提交失败时可复制交接。模型凭据错误需要在DSH自身设置处理，不向本插件提供账号或密钥。九类模块工具与九个Skill是不同概念，不能把注册数当作模型真实调用证明。

插件升级或移除不会替用户卸载 VPN 客户端。若需回退，先移除当前版本，再安装已保存的旧版 tgz；运行时会话和 DSH 全局配置不属于本插件发布包。
