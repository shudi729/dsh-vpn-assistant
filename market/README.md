# Publisher index

This directory contains a DSH format-1 index maintained by the plugin publisher.
After the npm release, users may add this HTTPS source in DSH's experimental
Custom plugin indexes feature:

`https://raw.githubusercontent.com/shudi729/dsh-vpn-assistant/v0.2.0/market/index.json`

This is a publisher-operated source. It is separate from dsh.so and from any
third-party community index.
