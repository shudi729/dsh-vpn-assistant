# Changelog

## 0.2.0 — 2026-11-12

- Added an explainable VPN selection engine, provider catalog, official-channel
  download guidance, and a seven-step installation wizard.
- Added nine runtime VPN skills grouped into four capabilities.
- Added an opt-in, read-only Windows local helper for device and DNS/TCP checks.
- Added eight original instructional SVG illustrations.
- Added DSH native-session context handoff with a copy fallback.

This is the first public release. DSH 0.2.1-rc.5 with the Web profile is the
only independently tested host version/profile combination.
